# michi.sweep

**Planned — v0.6. Not implemented yet; this stub is intentional.**

Declarative experiment grids (`sweep.yaml`: models × recipes × seeds) behind
the `michi sweep` verb: sequential or joblib-parallel execution, content-hash
caching, resume after interrupt, one run manifest per cell. Built on
`michi.bench`'s public surface.

See the project roadmap in the documentation.
