# michi.bench

**Planned — v0.3. Not implemented yet; this stub is intentional.**

Training and honest comparison of user-specified models behind the
`michi bench` verb: proper cross-validation, paired significance tests
(fold-correlation-corrected), confidence intervals, and plain-language
verdicts ("B beats A, but not significantly"). Built on `michi.evaluation`'s
public surface; heavy libraries (XGBoost, LightGBM, CatBoost) live behind the
`[bench]` extra.

See PLAN.md §11 and §15 (v0.3).
