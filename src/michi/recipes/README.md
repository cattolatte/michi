# michi.recipes

**Planned — v0.4. Not implemented yet; this stub is intentional.**

The **recipe** artifact (commented YAML of declarative cleaning/prep
operations plus a schema snapshot) and its three verbs: `michi clean`
(findings-driven interactive triage that authors a recipe), `michi apply`
(non-destructive execution with schema validation), and `michi export`
(compilation to a readable sklearn `Pipeline` script the user owns).

See the project roadmap in the documentation.
